# 校园交通：摆渡车 / 班车的数据源与结论

> 调研日期 **2026-09-27**。⚠️ 这份结论**直接决定「班车」功能怎么做**，动这块代码前先读这里。

---

## 0. 先纠正一个说法：**没有「校车」**

来自公众号「京工小喇叭」《北理【摆渡车】【班车】【校车】攻略》（2026 年中秋后发布）的原话：

> 首先应该清楚：我们学校只有两种车【摆渡车】【班车】——**【校车】其实不存在**，而且容易引发歧义。

⇒ **做功能时不要用「校车」这个词**。它指的就是「班车」。

---

## 1. 摆渡车（良乡校区独有）

| 项 | 内容 |
|---|---|
| 路线 | **地铁站（良乡大学城北站）→ 东校区南门 → 北校区南门**，循环 |
| 费用 | **刷校园卡免费**；外校/家长可从后门上，或让本校同学带 |
| 预约 | **不需要**，固定时间往返 |
| 固定发车点 | **只有两个**：良乡大学城北站 A 口公交牌处、北校区徐特立图书馆（= 北校区门口） |
| 中途停靠 | 东校区南门（**无固定发车时间**，在校门口等即可） |
| 规律 | **按星期变化**（工作日/周末不同）；**节假日有加发班次**；⚠️ **寒暑假可能调整**，以 i北理 为准 |

## 2. 班车（往返各校区）

| 项 | 内容 |
|---|---|
| 覆盖 | 良乡 / 中关村 / 西山 / 回龙观 等 |
| 耗时 | 良乡 ↔ 中关村 **50–90 分钟**（看路况） |
| 车型 | **普通班车** 与 **彩虹班车**（运营公司不同、站点相同） |
| ⚠️ **关键** | **两种都需要购票预约才能坐** —— 不是到点上车 |
| 购票（普通） | i北理 内预约，**学生最多只能提前 1 小时**买（老师无限制） |
| 购票（彩虹） | 在 i北理 会提示去**「彩虹巴士」公众号**预约，**可提前多日** |
| 候补 | 有空位且原乘客没来时才能上，**要问发车司机** |

### 乘车点

**良乡校区（3 个，班车依次经过 东站 → 北站 → 南站）**
- **东站**：文博中心、勤园、甘棠园、文萃之间十字路口 —— **无候车室**，得早点去
- **北站**：校医院处 —— 有候车室
- **南站**：化学实验中心、物理实验中心、南操场之间 —— 有候车室，可以晚点去

**中关村校区（2 个）**
- **国防科技园站**：国防科技园东侧入口（闸机口）旁小广场 —— 有候车室
- **光电楼站**：新南门附近宿舍楼（学生公寓 1 号 / 新一公寓）东侧 —— 无候车室，有站牌

## 3. 数据可靠性：两个来源都查过了

| 来源 | 时间 | 内容 | 可信度 |
|---|---|---|---|
| **官方**：良乡校区管理处「校园出行」`liangxiang.bit.edu.cn/cyfw/bjsj/index.htm` | 图片在 `2021-12/`、`2022-09/` 目录（**2021/2022 年上传**） | 班车时刻表 + 摆渡车时刻表（**每 20 分钟**） | 官方但**明显陈旧** |
| **第三方**：京工小喇叭公众号攻略 | 制表 **2026-05-05** | 摆渡车时刻表（**每 16 分钟**、含节假日加发）+ 站点/购票规则 | 新、细，但**非官方** |

⚠️ **两者的摆渡车班次对不上**（20 分钟 vs 16 分钟）—— 官方旧、第三方新，且第三方的更细。
⚠️ 另有一个第三方页面（buspedia）称中关村→良乡班车末班 **22:50**，而官方图写 **21:10**——
**无法核实的差异，不许合并进代码**。

### ⇒ 处理原则

1. **摆渡车**：以 2026-05-05 那份为准，但页面上**必须**标注
   「来源：京工小喇叭整理（2026-05-05）· 非官方 · 以 i北理 为准」
2. **班车**：⚠️ **不做发车提醒**（要先买票，提醒没意义）；只做
   **时刻表 + 乘车点 + 购票指引**（"要去 i北理 买票"这件事本身很多人不知道，是真正有价值的信息）
3. **绝不合并**来路不明的时间（如 22:50 那班）

## 4. 功能设计结论

| 做 | 不做 |
|---|---|
| ✅ **摆渡车**：选站点 → 「下一班 HH:mm，还有 N 分钟」+ 发车提醒 | ❌ 用「校车」这个说法 |
| ✅ 标清**数据来源与日期**，并给「看官方原图」入口 | ❌ 班车的发车提醒（要先购票预约） |
| ✅ 提示**节假日加发班次**可切换 | ❌ 把第三方与官方的时间**混着用** |
| ✅ 班车：**乘车点 + 购票指引**（"i北理 买票、学生只能提前 1 小时"） | ❌ 声称"实时"/"官方数据" |
