## 一、怎么干（已定）

| 项 | 决定 |
|---|---|
| **范围** | **三层递进**：① token/主题层（全局换肤）→ ② 组件库（规范 §5 的 9 类 × 6 态）→ ③ 逐屏替换（今天 → 课表 → 自习 → 我 → 设置页行式）。其余模块（图/网/话/座/设置二级页）**本阶段不动内容**，只跟着 token 换色 |
| **不做新旧 UI 开关** | 回退靠 `git revert` 单个提交 + 装上一个 tag 的包；维护两套渲染必然烂尾 |
| **token 落地** | 混合：Material3 承担能对上的角色（bg/surface/onSurface/primary/error/outline），M3 没有的（`--surface-2/3`、`--disabled-bg`、`--state-calm/attention/urgent`、12 色板、数字排版档）放 `GridTokens`（CompositionLocal） |
| **12 课名配色** | 色号 = `fnv1a32(课名) % 12`（**纯函数**，App / 桌面组件 / 通知三处必须调**同一个**函数；组件用 `toArgb()` 取色）。**禁止**「同一天内不重色」这类消解，也**禁止**本地 override 色表 —— 否则组件侧重算不出同一结果 |
| **分支** | `feature/grid-ui`（从 `master` 的 `3a4b7ca` 切出）。**不在 `master` 上直接做新 UI**；按阶段 merge 回来，`master` 始终可发布 |
| **版本** | 新 UI 线 **`1.12.0-alpha.N` / `versionCode 1001+`**，内部包**不推正式 tag**；正式发布 `1.12.0` 后沿用 `1001+` 继续。详见 [versioning.md §多分支并行时的号段隔离](versioning.md) |
| **验收** | 结构 / 语义 / **尺寸**（`uiautomator dump` 的 `bounds ÷ density` 得 dp，容差 ±2dp）。⚠️ **HTML 原型不能当像素基准**（字体/行高/栅格都不同），像素 diff 只用于新旧版本回归对比 |

## 五、这次要守的硬约束（踩过坑的）

1. **组件重绘不打网络**；快照**不许存有时效断言**（「正在上 X」每次本地现算）
2. **课程色跨 Tab / 抽屉 / 组件 / 通知一致** —— 靠"同一个纯哈希函数"，不靠同步
3. **组件库不能放 `:features:common`**（`theme` 反向依赖 `common`，会成环）；跨端共用纯逻辑放 `:data`
4. **不得绕过 token** 写 `Color(0xFF…)`（白名单：`features/theme`、`seat/SeatColors.kt`）
5. **出包后主动删旧包**，根目录**每条线各留最新 1 个**
6. **换包必须 `assembleRelease`**，判据是 `pm path` 的 mtime/size（`install -r` 的 "Success" 会静默回滚）
