## 0. 一句话结论

i北理 与我们有重叠的主要是**课表 / 考试 / 成绩 / 空教室 / 图书馆座位**，
其中 **「图书馆空间预约」我们已经在做，而且比它强**（见第三节）。

真正的空白只有三块值得看：**班车服务**、**校历**、**图书馆研讨间预约**。

## 三、⚠️ 一个重要更正：座位预约 = 图书馆座位

**此前我一直以为 `seatlib` 是「第三方自习座位系统」，与图书馆无关。错了。**

证据（2026-09-27 实测，只读免认证接口）：

```
POST https://seatlib.bit.edu.cn/api/Seat/tree   {"date":"2026-09-27"}
→ {"data":[{"id":"1","name":"徐特立馆","children":[
      {"id":"2","name":"三层","children":[
        {"id":"3","name":"视听学习空间"},
        {"id":"4","name":"自然科学图书第一阅览室"},
        {"id":"5","name":"自然科学图书第二阅览室"}, …]}]}]}
```

`seatlib` = **seat library**，就是**图书馆座位预约系统**（徐特立馆）。旁证：图书馆官网
（`lib.bit.edu.cn`）的《座位预约》说明与我们的契约**逐条一致**——「当日预约需开始后
**60 分钟内**刷卡签到」「次日预约需**次日 9:00 前**刷卡」「违约累计 **5 次**暂停预约 **7 日**」。

**这意味着**：

1. i北理 的「图书馆空间预约」和我们是**同一个后端**，只是它是网页/内嵌入口。
2. 我们不但没缺，反而**更强**：它只能「选座 → 预约」，我们有**抢座 / 监控 / 优先队列**，
   还有**签到时限提醒**（错过会记违约，这是官方没有任何提示的地方）。
3. ⚠️ **别再单独立项「图书馆座位预约」** —— 那是重复劳动。

## 五、明确不做（记下来，别反复讨论）

| 项 | 理由 |
|---|---|
| 校园支付 / 校园网充值 / 医药费报销 | 涉及**支付与资金**，第三方 App 碰不得 |
| 校门闸机 / 考勤打卡 | **隐私**（行踪数据），且与我们无关 |
| 公文发布 / 党费服务 / 协同办公 | 钉钉本职 |
| 消息 / 通讯录 | 同上 |
| 学生事务类办理（请销假、证明申请…） | 一次性低频操作，WebView 直达就是正解 |
| 延河课堂播放器 | 已有官方，我们只取 DDL / 动态这些**能进提醒**的部分 |
| 全校课表查询 | 查别人的课表，用途有限 |
| AI 问答（A+Campus / 智能客服） | 成本高、与我们的核心价值（组件 / 提醒 / 本地数据）无关 |
